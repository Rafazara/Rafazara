# Rafael Zaratin / Profile maintenance

This repository powers the public GitHub profile at https://github.com/Rafazara.

## Editorial principles

- Keep the personal identity **Rafael Zaratin / RZ** distinct from Zaratin Studios.
- Feature only public repositories and describe experiments accurately.
- Prefer a small, curated set of projects with clear READMEs.
- Never expose private repository names, private URLs, credentials, or client information.
- Avoid decorative emoji, noisy badge walls, and unverified performance claims.

## Update the profile

Edit `README.md` to adjust the introduction or projects. Update `assets/rz-banner.svg` for visual changes. The validation workflow checks local assets and editorial guardrails on each change.

GitHub profile pinned repositories are configured separately in the GitHub profile UI; editing this README does not change pins.

## Future improvements

Improve the documentation for public experimental projects before promoting them. Replace the profile avatar when ready. Add automated activity widgets only if their maintenance and privacy trade-offs justify them.
